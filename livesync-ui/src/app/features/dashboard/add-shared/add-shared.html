How to Share Documents & Folders

  • Get a Share Code: Right-click any document or folder and select "Share"
  • Copy the Code: The unique share code will be displayed
  • Share with Others: Send the code to anyone you want to collaborate with
  • Paste Here: Other users paste the code here to gain access
  • Folder Sharing: Sharing a folder grants access to all files and subfolders inside it
